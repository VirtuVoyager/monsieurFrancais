# Le passé composé avec avoir

Le passé composé raconte une action **terminée** dans le passé : *Samedi, j'**ai visité** un musée.*

## Formation : avoir au présent + participe passé

| | regarder |
|---|---|
| j' | **ai** regardé |
| tu | **as** regardé |
| il / elle / on | **a** regardé |
| nous | **avons** regardé |
| vous | **avez** regardé |
| ils / elles | **ont** regardé |

## Les participes passés

| verbes en | participe | exemples |
|---|---|---|
| -er | **-é** | parler → parl**é**, manger → mang**é** |
| -ir (finir) | **-i** | finir → fin**i**, choisir → chois**i**, dormir → dorm**i** |
| -re (vendre) | **-u** | attendre → attend**u**, répondre → répond**u** |

**Les irréguliers les plus fréquents :**

| | | | |
|---|---|---|---|
| avoir → **eu** | être → **été** | faire → **fait** | prendre → **pris** |
| boire → **bu** | lire → **lu** | voir → **vu** | dire → **dit** |
| écrire → **écrit** | mettre → **mis** | pouvoir → **pu** | vouloir → **voulu** |
| devoir → **dû** | recevoir → **reçu** | connaître → **connu** | ouvrir → **ouvert** |

## La négation

*Ne… pas* entoure l'**auxiliaire** : *Je **n**'ai **pas** vu le film. Nous **n**'avons **jamais** mangé de poutine.*

## Les marqueurs du récit

- **Quand ?** *hier, avant-hier, samedi dernier, la semaine dernière, il y a deux jours*.
- **Dans quel ordre ?** *d'abord, ensuite, puis, après, enfin, finalement*.

*D'**abord**, j'ai fait le ménage. **Ensuite**, j'ai téléphoné à ma mère. **Enfin**, j'ai regardé un film.*

À l'oral comme à l'écrit, ces mots rendent un récit clair : c'est un critère de la note (cohérence).
