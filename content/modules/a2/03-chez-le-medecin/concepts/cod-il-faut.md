# Avoir mal à, les pronoms compléments directs, il faut et devoir

## Avoir mal à

| | |
|---|---|
| à + le = **au** | *J'ai mal **au** dos, **au** ventre, **au** genou.* |
| à + la = **à la** | *J'ai mal **à la** tête, **à la** gorge, **à la** jambe.* |
| à + l' = **à l'** | *J'ai mal **à l**'oreille, **à l**'épaule.* |
| à + les = **aux** | *J'ai mal **aux** dents, **aux** yeux, **aux** pieds.* |

Autres symptômes : *J'ai **de la** fièvre. Je tousse. J'ai le nez qui coule. Je suis fatigué(e). Je me suis cassé le bras.*

**Depuis** + durée, avec le présent : *J'ai mal à la gorge **depuis** trois jours.*

## Les pronoms compléments d'objet direct (COD)

Ils remplacent un nom **sans préposition** après le verbe (*prendre **le** médicament*, *voir **la** médecin*) :

| | singulier | pluriel |
|---|---|---|
| masculin | **le** (l') | **les** |
| féminin | **la** (l') | **les** |

Aussi : *me, te, nous, vous*. *Le médecin **me** voit demain.*

**Place : devant le verbe conjugué.**

- *Tu prends le sirop ? — Oui, je **le** prends.*
- **Négation :** *Je **ne le** prends **pas**.*
- **Avec un infinitif** : devant l'infinitif : *Je vais **le** prendre.*
- **Au passé composé** : devant l'auxiliaire, et le participe s'accorde avec le COD placé avant : *L'ordonnance ? Je **l**'ai perdu**e**.*
- **À l'impératif affirmatif** : après le verbe : *Prenez-**le** trois fois par jour.*

## Il faut et devoir : l'obligation

- **Il faut** + infinitif (impersonnel, général) : ***Il faut** boire beaucoup d'eau.*
- **Devoir** + infinitif (avec une personne) : *Vous **devez** rester au lit.*

| devoir | |
|---|---|
| je dois | nous devons |
| tu dois | vous devez |
| il / elle doit | ils / elles doivent |

**Il ne faut pas** = c'est interdit : *Il ne faut pas fumer.* (≠ *ce n'est pas nécessaire*).
