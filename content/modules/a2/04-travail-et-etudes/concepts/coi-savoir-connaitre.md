# Les pronoms compléments indirects, savoir et connaître

## Les pronoms COI : lui, leur

Ils remplacent une **personne** introduite par **à** : *parler **à**, téléphoner **à**, écrire **à**, répondre **à**, demander **à**, envoyer quelque chose **à**, dire **à**, donner **à**.*

| | singulier | pluriel |
|---|---|---|
| masculin ou féminin | **lui** | **leur** |

Aussi : *me, te, nous, vous*. *Ma cheffe **me** donne des conseils.*

- *Je téléphone **à mon collègue**.* → *Je **lui** téléphone.*
- *J'écris **à mes clients**.* → *Je **leur** écris.*
- *Lui* sert pour un homme **et** pour une femme : *Je parle à Julie → je **lui** parle.*

**Place :** comme les COD, devant le verbe conjugué, devant l'infinitif, ou après l'impératif affirmatif :

*Je ne **lui** ai pas répondu. Je vais **leur** envoyer le rapport. Écrivez-**lui** !*

**COD ou COI ?** *Je vois Marc* (COD → je **le** vois) ; *Je parle à Marc* (COI → je **lui** parle).
Attention à *leur* pronom (invariable : *je **leur** parle*) et *leur(s)* possessif (*leurs collègues*).

## Savoir et connaître

| | savoir | connaître |
|---|---|---|
| je | sais | connais |
| tu | sais | connais |
| il / elle | sait | connaît |
| nous | savons | connaissons |
| vous | savez | connaissez |
| ils / elles | savent | connaissent |
| participe | su | connu |

- **Savoir** + infinitif (une compétence) : *Je **sais** utiliser Excel.*
- **Savoir** + *que, où, quand, si, comment* : *Tu **sais** où est la réunion ?*
- **Connaître** + nom (une personne, un lieu, une chose qu'on a rencontrée) : *Je **connais** bien Montréal. Vous **connaissez** ce logiciel ?*
