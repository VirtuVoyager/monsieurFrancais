# Le comparatif, le superlatif et les pronoms démonstratifs

## Le comparatif

| | avec un adjectif ou un adverbe | avec un nom | avec un verbe |
|---|---|---|---|
| + | **plus** cher **que** | **plus de** choix **que** | il dépense **plus que** moi |
| = | **aussi** cher **que** | **autant de** choix **que** | il dépense **autant que** moi |
| − | **moins** cher **que** | **moins de** choix **que** | il dépense **moins que** moi |

L'adjectif s'accorde : *Cette veste est plus chèr**e** que l'autre.*

**Formes irrégulières :**

| | | |
|---|---|---|
| bon(ne) | → **meilleur(e)** | *Ce café est **meilleur** que l'autre.* (jamais *plus bon*) |
| bien | → **mieux** | *Ce modèle fonctionne **mieux**.* |
| mauvais | → **pire** ou plus mauvais | *Le service est **pire** qu'avant.* |

## Le superlatif

**le / la / les + plus / moins + adjectif (+ de)** :

- *C'est **le** magasin **le plus** grand **de** la ville.*
- *C'est **la** solution **la moins** chère.*
- *C'est **le meilleur** prix. C'est ici qu'on mange **le mieux**.*

## Les pronoms démonstratifs

Ils évitent de répéter un nom :

| | singulier | pluriel |
|---|---|---|
| masculin | **celui** | **ceux** |
| féminin | **celle** | **celles** |

- Avec **-ci / -là** pour montrer : *Je préfère **celui-ci**, pas **celui-là**.*
- Avec **de** : *Mon téléphone est plus récent que **celui de** mon frère.*
- Avec **qui / que** : *Prenez **celle qui** est en promotion.*

## Pour acheter

*Je cherche… / Vous avez ça en taille M ? / Je peux l'essayer ? / C'est en solde ? / Je voudrais l'échanger / être remboursé(e).*
