# Le futur simple et la phrase avec si

## Formation

**Infinitif + terminaisons** (pour les verbes en *-re*, on enlève le *e* final) :

| | parler | finir | prendre |
|---|---|---|---|
| je | parler**ai** | finir**ai** | prendr**ai** |
| tu | parler**as** | finir**as** | prendr**as** |
| il / elle / on | parler**a** | finir**a** | prendr**a** |
| nous | parler**ons** | finir**ons** | prendr**ons** |
| vous | parler**ez** | finir**ez** | prendr**ez** |
| ils / elles | parler**ont** | finir**ont** | prendr**ont** |

Les terminaisons ressemblent au verbe *avoir* au présent : *-ai, -as, -a, -ons, -ez, -ont*.

**Radicaux irréguliers** (les terminaisons restent les mêmes) :

| | | | |
|---|---|---|---|
| être → **ser**ai | avoir → **aur**ai | aller → **ir**ai | faire → **fer**ai |
| venir → **viendr**ai | voir → **verr**ai | pouvoir → **pourr**ai | vouloir → **voudr**ai |
| devoir → **devr**ai | savoir → **saur**ai | falloir → il **faudr**a | envoyer → **enverr**ai |

## Futur proche ou futur simple ?

- **Futur proche** (*je vais partir*) : une action proche, décidée, très courante à l'oral.
- **Futur simple** (*je partirai*) : un projet plus lointain, une prévision, une promesse, un texte écrit.
*Je **vais déménager** samedi. Un jour, j'**achèterai** une maison.*

## Quand + futur

Contrairement à l'anglais, on met le **futur** après *quand* si l'action est future :
***Quand** je **serai** au Canada, je chercherai du travail.* (et non ~~quand je suis~~)

## L'hypothèse : si + présent → futur

Pour une condition **possible** :

**Si** + présent, … futur (ou impératif) :

- ***Si** tu **viens** à Ottawa, nous **visiterons** le Parlement.*
- ***S'il** pleut, **restez** à la maison.*

Jamais de futur juste après *si* : ~~si tu viendras~~. *Si* devient *s'* devant *il / ils* : *s'il, s'ils*.

## Les marqueurs du futur

*demain, bientôt, dans deux ans, l'année prochaine, plus tard, un jour, à l'avenir*.
