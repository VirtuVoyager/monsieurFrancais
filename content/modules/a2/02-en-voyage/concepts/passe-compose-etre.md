# Le passé composé avec être

## Quels verbes prennent être ?

1. **Les verbes de mouvement ou de changement d'état** (souvent appris avec « la maison d'être ») :

| | | |
|---|---|---|
| aller / venir | arriver / partir | entrer / sortir |
| monter / descendre | naître / mourir | rester / tomber |
| retourner / revenir / devenir | passer (par) | rentrer |

2. **Tous les verbes pronominaux** : *se lever, se promener, s'amuser, se perdre…*

Les autres verbes (la grande majorité) prennent **avoir** : *j'ai visité, j'ai pris, j'ai vu*.

## L'accord du participe passé avec être

Avec **être**, le participe s'accorde avec le **sujet**, comme un adjectif :

| | aller |
|---|---|
| je suis allé(**e**) | nous sommes allé(**e**)**s** |
| tu es allé(**e**) | vous êtes allé(**e**)(**s**) |
| il est allé / elle est allé**e** | ils sont allé**s** / elles sont allé**es** |

- *Marie est arrivé**e**. Mes parents sont parti**s**. Mes sœurs sont venu**es**.*
- Participes irréguliers : *venir → venu, naître → né, mourir → mort*.

## Les verbes pronominaux

Le pronom réfléchi se place devant **être** :

*Je **me suis** levé(e). Elle **s'est** promené**e**. Nous **nous sommes** perdu**s**.*

**Négation :** *Je **ne** me suis **pas** réveillé à l'heure.*

## Attention

*Sortir, monter, descendre, passer* prennent **avoir** quand ils ont un complément d'objet :
*Je **suis** sorti.* mais *J'**ai** sorti la valise de la voiture.*
