# Pays, villes et nationalités

## Le genre des pays

Un pays a un genre, et ce genre choisit la préposition. Une ville n'a pas d'article.

| Règle | Genre | Exemples |
|---|---|---|
| Le nom se termine par **-e** | féminin | la France, l'Inde, la Chine, l'Italie, la Suisse |
| Le nom ne se termine pas par -e | masculin | le Canada, le Japon, le Maroc, le Sénégal, le Portugal |
| Le nom est au pluriel | pluriel | les États-Unis, les Pays-Bas, les Philippines |

**Attention :** quelques pays en *-e* sont masculins : *le Mexique, le Cambodge, le Mozambique, le Zimbabwe, le Belize*.

## Où ? D'où ? Les prépositions

| Lieu | Aller, habiter, travailler… | Venir de… |
|---|---|---|
| une ville | **à** Paris, **à** Montréal | **de** Paris, **de** Montréal |
| un pays féminin | **en** France, **en** Inde | **de** France, **d'**Inde |
| un pays masculin | **au** Canada, **au** Japon | **du** Canada, **du** Japon |
| un pays masculin qui commence par une voyelle | **en** Iran, **en** Équateur | **d'**Iran, **d'**Équateur |
| un pays au pluriel | **aux** États-Unis | **des** États-Unis |

*au* = à + le, *aux* = à + les, *du* = de + le, *des* = de + les.

Les provinces et les régions suivent la même règle que les pays : *au Québec, en Ontario, en Colombie-Britannique, au Manitoba*.

## Le verbe venir

| | |
|---|---|
| je **viens** | nous **venons** |
| tu **viens** | vous **venez** |
| il / elle / on **vient** | ils / elles **viennent** |

*Je viens d'Inde. — D'où venez-vous ? — Nous venons du Maroc.*

## Les nationalités

Une nationalité est un adjectif : pas d'article, et une **minuscule**. *Il est canadien.* (Le nom des habitants prend une majuscule : *les Canadiens*.)

| Masculin | Féminin | Règle |
|---|---|---|
| français, chinois | française, chinoise | + **e** |
| espagnol, marocain, mexicain | espagnole, marocaine, mexicaine | + **e** (le *n* de *-ain* ne double pas) |
| indien, canadien, italien | indienne, canadienne, italienne | **-ien → -ienne** |
| belge, russe, suisse | belge, russe, suisse | déjà en *-e* : pas de changement |
| grec | grecque | irrégulier |

**Je suis** + nationalité, **je viens de** + pays : *Je suis indienne. Je viens d'Inde.*
