# Les verbes pronominaux, aller, faire et l'heure

## Les verbes pronominaux

Ces verbes ont un pronom réfléchi qui reprend le sujet : *se lever, se réveiller, se laver, s'habiller, se coucher, se reposer*.

| se lever | |
|---|---|
| je **me** lève | nous **nous** levons |
| tu **te** lèves | vous **vous** levez |
| il / elle / on **se** lève | ils / elles **se** lèvent |

- Devant une voyelle ou un *h* muet : *je **m**'habille, il **s**'appelle*.
- **Négation :** le *ne… pas* entoure le pronom et le verbe : *Je **ne** me lève **pas** tôt.*
- Attention à l'accent : *je l**è**ve*, *nous levons*.

## Aller et faire au présent

| | aller | faire |
|---|---|---|
| je | vais | fais |
| tu | vas | fais |
| il / elle / on | va | fait |
| nous | allons | faisons |
| vous | allez | faites |
| ils / elles | vont | font |

- *Aller* + lieu : *Je vais **au** bureau, **à la** banque, **à l**'école.*
- *Faire* sert pour beaucoup d'activités : *faire la cuisine, faire les courses, faire du sport, faire le ménage*.

## Dire l'heure

*Quelle heure est-il ? — Il est…*

| | |
|---|---|
| 8 h 00 | huit heures |
| 8 h 15 | huit heures **et quart** |
| 8 h 30 | huit heures **et demie** |
| 8 h 45 | neuf heures **moins le quart** |
| 12 h 00 / 0 h 00 | midi / minuit |
| 18 h 20 | dix-huit heures vingt (six heures vingt du soir) |

Pour une action : *Je commence **à** neuf heures. Je travaille **de** neuf heures **à** dix-sept heures.*
