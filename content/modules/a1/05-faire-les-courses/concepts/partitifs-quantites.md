# Les partitifs, les quantités, vouloir et pouvoir

## Les articles partitifs

On les utilise pour une quantité qu'on ne compte pas (une partie d'une chose) :

| masculin | féminin | devant une voyelle | pluriel |
|---|---|---|---|
| **du** pain | **de la** viande | **de l**'eau | **des** fruits |

- *Je mange **du** riz. Elle boit **de l**'eau. Nous achetons **des** légumes.*
- Avec les verbes de goût, on garde l'article **défini** : *J'aime **le** fromage* (en général), mais *Je mange **du** fromage* (une quantité).

## La négation

Après une négation, du / de la / de l' / des deviennent **de** (d') :

- *Je bois du café.* → *Je **ne** bois **pas de** café.*
- *Il y a de l'eau.* → *Il **n**'y a **plus d**'eau.*

## Les quantités : toujours « de »

Après une quantité précise ou un adverbe de quantité, on utilise **de** seul :

| | |
|---|---|
| un kilo **de** pommes | une bouteille **d**'eau |
| un litre **de** lait | une tranche **de** jambon |
| un paquet **de** pâtes | une boîte **de** thon |
| beaucoup **de** sucre | un peu **de** sel |
| trop **de** sel | assez **de** pain |

## Vouloir et pouvoir

| | vouloir | pouvoir |
|---|---|---|
| je | veux | peux |
| tu | veux | peux |
| il / elle / on | veut | peut |
| nous | voulons | pouvons |
| vous | voulez | pouvez |
| ils / elles | veulent | peuvent |

- Pour commander poliment, on dit ***je voudrais*** (et non *je veux*) : *Je voudrais un café, s'il vous plaît.*
- Ces verbes sont suivis d'un infinitif : *Je **peux payer** par carte ? Vous **voulez goûter** ?*

## Demander le prix

*C'est combien ? — Combien coûte le fromage ? — Combien coûtent les fraises ? — Ça fait combien ?*
