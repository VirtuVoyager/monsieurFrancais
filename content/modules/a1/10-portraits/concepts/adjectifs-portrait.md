# Les adjectifs, c'est / il est et les pronoms toniques

## L'accord de l'adjectif

L'adjectif s'accorde avec le nom : masculin ou féminin, singulier ou pluriel.

| Masculin | Féminin | Règle |
|---|---|---|
| grand, petit, brun | grande, petite, brune | + **e** |
| jeune, calme, timide, drôle | jeune, calme, timide, drôle | déjà en *-e* : pas de changement |
| sérieux, généreux, heureux | sérieuse, généreuse, heureuse | **-eux → -euse** |
| sportif, actif | sportive, active | **-f → -ve** |
| gentil, italien, bon | gentille, italienne, bonne | la consonne double + **e** |
| gros | grosse | **-s → -sse** |

**Au pluriel**, on ajoute **-s** : *des enfants calmes, des filles sportives*. Un adjectif en *-s* ou *-x* ne change pas : *des hommes sérieux*.

Un groupe **mixte** prend le **masculin pluriel** : *Paul et Léa sont contents.*

## Trois adjectifs irréguliers

| Masculin | Masculin devant une voyelle | Féminin |
|---|---|---|
| beau | **bel** (un bel homme) | belle |
| nouveau | **nouvel** (un nouvel ami) | nouvelle |
| vieux | **vieil** (un vieil ami) | vieille |

## La place de l'adjectif

La plupart des adjectifs se placent **après** le nom : *un homme sympathique, une femme sportive*.

Quelques adjectifs courts se placent **avant** : *beau, joli, jeune, vieux, nouveau, grand, petit, bon, mauvais*. *Une jolie maison, un jeune médecin, un petit village.*

## C'est ou il est ?

| C'est… | Il est / Elle est… |
|---|---|
| + un nom avec un article : *C'est un ami. C'est une collègue.* | + un adjectif : *Il est grand. Elle est gentille.* |
| + un nom propre : *C'est Marc.* | + une profession ou une nationalité sans article : *Il est infirmier. Elle est canadienne.* |
| + un pronom tonique : *C'est moi.* | |

## Les pronoms toniques

| je | tu | il | elle | nous | vous | ils | elles |
|---|---|---|---|---|---|---|---|
| **moi** | **toi** | **lui** | **elle** | **nous** | **vous** | **eux** | **elles** |

On les utilise pour **insister** (*Moi, je suis calme. Lui, il est bavard.*), après **c'est** (*C'est lui.*), après une **préposition** (*avec moi, chez eux, pour toi*) et dans **Et toi ?**
