# Le futur proche, le passé récent et les dates

## Le futur proche : aller + infinitif

Pour un projet ou une action proche, on conjugue **aller** au présent et on ajoute l'infinitif :

| | |
|---|---|
| je **vais** partir | nous **allons** partir |
| tu **vas** partir | vous **allez** partir |
| il / elle / on **va** partir | ils / elles **vont** partir |

- *Ce week-end, je **vais visiter** le Vieux-Québec.*
- **Négation :** *ne… pas* entoure *aller* : *Je **ne vais pas** sortir ce soir.*
- Avec un verbe pronominal, le pronom reste devant l'infinitif : *Je vais **me** coucher tôt.*

## Le passé récent : venir de + infinitif

Pour une action qui vient juste de se terminer :

- *Je **viens de** finir mon travail.* (= il y a quelques minutes)
- *Nous **venons d'**arriver au Canada.*
- *Le cours **vient de** commencer.*

## Les expressions de temps

| passé | présent | futur |
|---|---|---|
| hier | aujourd'hui | demain |
| la semaine dernière | cette semaine | la semaine prochaine |
| le mois dernier | ce mois-ci | le mois prochain |
| l'année dernière | cette année | l'année prochaine |

## Les dates

- Les jours : *lundi, mardi, mercredi, jeudi, vendredi, samedi, dimanche* (sans majuscule).
- Les mois : *janvier, février, mars, avril, mai, juin, juillet, août, septembre, octobre, novembre, décembre*.
- **Le** + jour + nombre + mois : *le vendredi 14 mars*. Le premier jour : *le **1er** (premier) mai*.
- **En** + mois ou année : *en juillet, en 2027*. **Au** printemps, mais **en** été, **en** automne, **en** hiver.
- *Quelle est la date aujourd'hui ? — Nous sommes le 3 octobre. / C'est le 3 octobre.*
