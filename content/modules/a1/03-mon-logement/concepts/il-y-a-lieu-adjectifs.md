# Il y a, les prépositions de lieu et l'accord des adjectifs

## Il y a

*Il y a* présente ce qui existe dans un lieu. Il ne change pas au pluriel :

- *Il y a **un** salon et **deux** chambres.*
- À la négation, un / une / des deviennent **de** : *Il n'y a **pas de** balcon.*
- Pour poser la question : *Est-ce qu'il y a un ascenseur ?* ou *Y a-t-il un ascenseur ?*

## Les prépositions de lieu

| | |
|---|---|
| dans | *Le lit est **dans** la chambre.* |
| sur / sous | *Le livre est **sur** la table. Le chat est **sous** la table.* |
| devant / derrière | *Le jardin est **derrière** la maison.* |
| entre | *La salle de bains est **entre** les deux chambres.* |
| à côté de / en face de / près de / loin de | *J'habite **près de** la gare, **en face de** la banque.* |
| à gauche / à droite (de) | *La cuisine est **à droite**.* |

Après **de**, l'article se contracte : *à côté **du** salon* (de + le), *près **des** magasins* (de + les), mais *à côté **de la** fenêtre, près **de l'**école*.

## L'accord des adjectifs

L'adjectif prend le genre et le nombre du nom :

| masculin | féminin | pluriel |
|---|---|---|
| petit | petit**e** | petit**s** / petit**es** |
| moderne | moderne | moderne**s** |
| lumineux | lumineu**se** | lumineux / lumineu**ses** |
| ancien | ancien**ne** | ancien**s** / ancien**nes** |
| beau (bel) | belle | beaux / belles |
| nouveau (nouvel) | nouvelle | nouveaux / nouvelles |

**Place :** la plupart des adjectifs viennent **après** le nom (*un salon lumineux, une cuisine moderne*). Quelques adjectifs courts viennent **avant** : *grand, petit, beau, joli, nouveau, vieux, bon, mauvais* (*un grand appartement, une jolie maison*).

Devant une voyelle : *un **bel** appartement, un **nouvel** immeuble, un **vieil** immeuble*.
