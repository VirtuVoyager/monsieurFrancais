# Poser des questions, jouer à et faire de

## Trois façons de poser une question

| registre | exemple |
|---|---|
| familier (intonation) | *Tu aimes le cinéma ?* |
| courant (est-ce que) | ***Est-ce que** tu aimes le cinéma ?* |
| soutenu (inversion) | ***Aimes-tu** le cinéma ?* |

- Avec l'inversion, on met un trait d'union : *aimez-vous, parlez-vous*.
- Si le verbe finit par une voyelle devant *il / elle / on*, on ajoute **-t-** : ***Aime-t-il** le sport ? **Va-t-elle** au parc ?*
- À l'examen (entretien et interaction), *est-ce que* est toujours correct et facile.

## Les mots interrogatifs

| | |
|---|---|
| **Qu'est-ce que** / **Que** | *Qu'est-ce que tu fais ? Que fais-tu ?* |
| **Où** | *Où est-ce que vous allez ?* |
| **Quand** | *Quand est-ce que le cours commence ?* |
| **Comment** | *Comment allez-vous au travail ?* |
| **Pourquoi** — parce que | *Pourquoi aimes-tu l'hiver ? — **Parce que** j'aime le ski.* |
| **Combien (de)** | *Combien de livres lis-tu par mois ?* |
| **Qui** | *Avec qui fais-tu du sport ?* |
| **Quel / Quelle / Quels / Quelles** | *Quel sport pratiquez-vous ? Quelle est ta saison préférée ?* |

## Parler de ses goûts

*aimer, adorer, préférer, détester* + article défini ou infinitif :
*J'adore **la** musique. Je préfère **lire**. Je n'aime pas **le** froid.*

## Jouer à, faire de

| | |
|---|---|
| **jouer à** + jeu, sport d'équipe | *jouer **au** soccer, **au** hockey, **aux** cartes, **à la** pétanque* |
| **jouer de** + instrument | *jouer **du** piano, **de la** guitare* |
| **faire de** + activité | *faire **du** vélo, **de la** natation, **du** ski, **de la** randonnée* |

## La météo

*Quel temps fait-il ?* — *Il fait beau / mauvais / chaud / froid / frais. Il y a du soleil / du vent / des nuages. Il pleut. Il neige. Il fait vingt degrés.*
