# Donner son opinion et organiser ses idées

## Exprimer son opinion

| certitude → **indicatif** | doute / négation → **subjonctif** |
|---|---|
| *Je pense que…* | *Je ne pense pas que…* |
| *Je crois que…* | *Je ne crois pas que…* |
| *Je trouve que…* | *Je doute que…* |
| *Il est clair / évident / sûr que…* | *Il est possible que… / Il se peut que…* |
| *À mon avis, … / Selon moi, … / D'après moi, …* | *Il n'est pas certain que…* |

- *Je pense que les études **sont** trop chères.*
- *Je ne pense pas que les études **soient** gratuites un jour.*
- *Il est possible que l'école **ferme** l'an prochain.*

Pour nuancer : *Je suis plutôt d'accord / pas du tout d'accord avec… — Je comprends ce point de vue, mais… — Il est vrai que…, cependant…*

## Les connecteurs logiques

| idée | connecteurs |
|---|---|
| **ajouter** | *de plus, en plus, en outre, par ailleurs, également* |
| **opposer** | *mais, cependant, pourtant, toutefois, par contre, en revanche, alors que* |
| **cause** | *parce que, car, puisque, comme* (début de phrase), *grâce à* (+ positif), *à cause de* (+ négatif) |
| **conséquence** | *donc, alors, c'est pourquoi, par conséquent, si bien que* |
| **exemple** | *par exemple, notamment, comme* |
| **conclure** | *en conclusion, pour conclure, finalement, en somme* |

**Structurer un texte d'opinion (tâche 2 et 3) :**

1. Introduire : *De nos jours, … — On se demande souvent si…*
2. Premier argument : *D'abord / Premièrement, … Par exemple, …*
3. Opposer ou ajouter : *D'une part, … d'autre part, … — En revanche, …*
4. Conclure et donner son avis : *Pour conclure, je pense que…*

## Grâce à / à cause de + nom ; parce que + phrase

*Il a réussi **grâce à** son professeur.* — *Il a échoué **à cause de** son absence.* — *Il a réussi **parce qu**'il a beaucoup travaillé.*
