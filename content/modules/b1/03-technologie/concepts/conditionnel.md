# Le conditionnel présent et l'hypothèse avec si

## Formation : radical du futur + terminaisons de l'imparfait

| | aimer | finir | prendre |
|---|---|---|---|
| je | aimer**ais** | finir**ais** | prendr**ais** |
| tu | aimer**ais** | finir**ais** | prendr**ais** |
| il / elle / on | aimer**ait** | finir**ait** | prendr**ait** |
| nous | aimer**ions** | finir**ions** | prendr**ions** |
| vous | aimer**iez** | finir**iez** | prendr**iez** |
| ils / elles | aimer**aient** | finir**aient** | prendr**aient** |

Les radicaux irréguliers sont ceux du futur : *être → **ser**ais, avoir → **aur**ais, aller → **ir**ais, faire → **fer**ais, pouvoir → **pourr**ais, vouloir → **voudr**ais, devoir → **devr**ais, venir → **viendr**ais, savoir → **saur**ais, falloir → il **faudr**ait*.

Attention à la prononciation : *je parler**ai*** (futur, [e]) ≠ *je parler**ais*** (conditionnel, [ɛ]).

## Les usages

| usage | exemple |
|---|---|
| **politesse** | *Je **voudrais** un renseignement. **Pourriez**-vous m'aider ?* |
| **souhait** | *J'**aimerais** travailler à distance.* |
| **conseil** | *Tu **devrais** désactiver les notifications. À ta place, je **ferais** une pause.* |
| **information non confirmée** (médias) | *Les écrans **nuiraient** au sommeil.* (= selon certains) |
| **hypothèse, imagination** | *Avec plus d'argent, j'**achèterais** une maison.* |

## L'hypothèse : si + imparfait → conditionnel

Pour une situation **imaginaire** ou **peu probable** maintenant :

***Si** j**'avais** plus de temps, j**'apprendrais** à coder.*
*Je **serais** plus calme **si** je **lisais** moins de nouvelles.*

**Comparez les trois hypothèses :**

| | si + … | résultat |
|---|---|---|
| possible (futur) | **présent** : *Si j'ai le temps,* | **futur** : *je t'appellerai.* |
| imaginaire (présent) | **imparfait** : *Si j'avais le temps,* | **conditionnel** : *je t'appellerais.* |

**Jamais de futur ni de conditionnel juste après *si*** : ~~si j'aurais~~.

## Pour l'examen

À la tâche 2 de l'expression orale, le conditionnel de politesse est attendu : *Est-ce que vous **pourriez** me dire… ? J**'aimerais** savoir si… Ce **serait** possible de… ?*
