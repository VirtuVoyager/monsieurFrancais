# Dont, ce qui / ce que et la mise en relief

## Le pronom relatif dont

**Dont** remplace un complément introduit par **de** :

| verbe / expression + de | exemple |
|---|---|
| parler **de** | *C'est le régime **dont** tout le monde parle.* |
| avoir besoin **de** | *Voici le matériel **dont** vous avez besoin.* |
| avoir peur **de** | *C'est la maladie **dont** j'avais peur.* |
| s'occuper **de** | *Les patients **dont** elle s'occupe sont âgés.* |
| être fier / content **de** | *C'est un résultat **dont** je suis fier.* |

**Dont** sert aussi pour la possession : *J'ai une amie **dont** le frère est médecin.* (= le frère **de** cette amie)

**Rappel :** **qui** = sujet, **que** = COD, **où** = lieu ou temps, **dont** = complément avec *de*.

## Ce qui, ce que, ce dont

Quand il n'y a pas de nom avant le relatif, on ajoute **ce** (= *la chose qui / que / dont*) :

- ***Ce qui*** (sujet) : *Ce qui est important, c'est de bien dormir.*
- ***Ce que*** (COD) : *Fais **ce que** le médecin t'a dit.*
- ***Ce dont*** (avec *de*) : *Le repos, c'est **ce dont** tu as besoin.*

Ils sont fréquents dans les questions indirectes : *Je ne sais pas **ce qui** se passe. Dites-moi **ce que** vous voulez.*

## La mise en relief : c'est… qui / c'est… que

Pour insister sur un élément de la phrase :

- sur le **sujet** : ***C'est** le manque de sommeil **qui** me fatigue.*
- sur un **autre élément** : ***C'est** le matin **que** je fais du sport. **C'est** à mon médecin **que** j'ai parlé.*
- au pluriel, on peut dire ***ce sont** … qui* : *Ce sont les écrans qui nous empêchent de dormir.*

**Ce qui… / Ce que…, c'est…** est très utile à l'oral pour souligner une idée :
*Ce que j'aime dans le yoga, **c'est** le calme.*
