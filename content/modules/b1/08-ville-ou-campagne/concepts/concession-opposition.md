# La concession, l'opposition et l'argumentation

## Opposer deux idées

*Alors que, tandis que, mais, en revanche, par contre* opposent deux faits :

*En ville, on se déplace à pied, **alors qu**'à la campagne, on prend la voiture.*

## La concession : reconnaître une idée, puis la nuancer

La concession dit : « c'est vrai, **mais** cela ne change pas la conclusion ».

| connecteur | construction | exemple |
|---|---|---|
| **bien que** / **quoique** | + **subjonctif** | ***Bien que** la ville **soit** bruyante, j'aime y vivre.* |
| **même si** | + **indicatif** | ***Même si** la ville **est** bruyante, j'aime y vivre.* |
| **malgré** | + **nom** | ***Malgré** le bruit, j'aime vivre en ville.* |
| **pourtant**, **cependant**, **toutefois**, **néanmoins** | début de proposition | *La ville est bruyante ; **pourtant**, j'aime y vivre.* |
| **avoir beau** | + infinitif | *J'**ai beau** chercher, je ne trouve pas de logement.* |
| **il est vrai que…, mais…** | indicatif | ***Il est vrai que** la campagne est calme, **mais** elle est isolée.* |

**Attention :** *malgré **que*** est à éviter ; dites *bien que*.

## Construire un argument en trois temps

1. **Thèse** (ce que vous pensez) : *À mon avis, la ville offre plus d'opportunités.*
2. **Justification + exemple** : *En effet, on y trouve plus d'emplois. Par exemple, dans mon domaine, presque tous les postes sont à Montréal.*
3. **Concession + réfutation** : ***Bien sûr**, les loyers sont plus élevés. **Cependant**, on économise sur la voiture.*

## Pour la tâche 3 de l'expression orale

- **Reformuler le sujet** : *Le sujet porte sur… / On se demande si…*
- **Donner son avis** : *Personnellement, je suis plutôt d'accord / en désaccord avec cette idée.*
- **Enchaîner** : *D'abord… Ensuite… De plus… Enfin…*
- **Concéder** : *Certes… mais… / Il est vrai que… cependant…*
- **Conclure** : *En somme / Pour conclure, je dirais que…*

Une réponse qui présente les deux points de vue, puis tranche, est plus convaincante qu'une liste d'arguments d'un seul côté.
