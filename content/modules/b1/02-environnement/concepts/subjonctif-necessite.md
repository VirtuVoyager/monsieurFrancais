# Le subjonctif présent : nécessité et volonté

## Quand l'utiliser ?

Le subjonctif s'emploie dans une proposition introduite par **que**, après un verbe ou une expression qui exprime :

| | |
|---|---|
| la **nécessité** | *il faut que, il est nécessaire que, il est important que, il est essentiel que* |
| la **volonté**, le souhait | *vouloir que, souhaiter que, aimer que, préférer que, demander que* |
| (plus tard) le sentiment, le doute | *être content que, avoir peur que, douter que…* |

*Il faut que nous **réduisions** nos déchets. Je souhaite que la ville **plante** plus d'arbres.*

## Formation (verbes réguliers)

Radical de **ils** au présent + **-e, -es, -e, -ions, -iez, -ent** :

| | trier (ils **tri**ent) | finir (ils **finiss**ent) | prendre (ils **prenn**ent) |
|---|---|---|---|
| que je | trie | finisse | prenne |
| que tu | tries | finisses | prennes |
| qu'il / elle | trie | finisse | prenne |
| que nous | tri**ions** | finiss**ions** | pren**ions** |
| que vous | tri**iez** | finiss**iez** | pren**iez** |
| qu'ils / elles | trient | finissent | prennent |

Pour *nous* et *vous*, la forme ressemble à l'imparfait : *que nous prenions, que vous veniez*.

## Les irréguliers essentiels

| | | | |
|---|---|---|---|
| être : que je **sois**, nous **soyons** | avoir : que j**'aie**, nous **ayons** | faire : que je **fasse** | aller : que j**'aille**, nous **allions** |
| pouvoir : que je **puisse** | savoir : que je **sache** | vouloir : que je **veuille**, nous **voulions** | falloir : qu'il **faille** |

## Subjonctif ou infinitif ?

- **Sujets différents** → *que* + subjonctif : *Je veux **que tu recycles**.*
- **Même sujet** → infinitif : *Je veux **recycler**.* (et non ~~je veux que je recycle~~)
- Expression impersonnelle **générale** → infinitif : ***Il faut** recycler.* / **précise** → subjonctif : ***Il faut que** vous recycliez.*

## Pour l'examen

Une ou deux structures au subjonctif bien employées (*il faudrait que…, il est essentiel que…*) montrent un niveau B1 solide en expression écrite et orale.
